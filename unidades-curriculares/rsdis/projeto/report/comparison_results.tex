These differences describe this small batch. Variation between layouts and
ROS/Gazebo execution schedules prevents attributing every timing difference
solely to the heuristic. There are no repeated executions of each fixed case,
and these data do not establish statistical superiority.

Delivered-detection position RMSE ranges from 0.190 to
0.328 m per run. Repeated frames are correlated and sample
counts differ with the routes; this is a descriptive perception check. The outage
cases record 3052 lost application delivery attempts and
460 retries across both policies, while all four finish.
