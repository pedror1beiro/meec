# Firmware PRUMO

O código está em [PRUMO](PRUMO/README.md), incluindo dependências HAL/CMSIS e projeto nativo STM32CubeIDE.

Consultar [instruções Linux](../docs/08-linux-cubeide.md). A configuração HAL está escrita em C; não é necessário gerar um projeto novo no CubeMX para compilar o projeto existente. A compilação para Cortex-M3 foi validada; o ensaio físico da board continua pendente.
